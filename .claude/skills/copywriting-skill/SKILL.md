# copywriting Skill

> Showcase version — abbreviated skill spec.

## Purpose

Transform a single source article into platform-tailored copy for: 掘金 / 知乎 / CSDN / Twitter.

## Per-platform style cheatsheet

| Platform | Tone | Length | Hook style |
|---|---|---|---|
| 掘金 | Engineering, dense | 1500-3000 字 | Code-led |
| 知乎 | Reflective, narrative | 2000-4000 字 | Question-led |
| CSDN | Tutorial, stepwise | 1000-2500 字 | Problem-led |
| Twitter | Punchy, thread | 5-10 tweets | Stat-led |
